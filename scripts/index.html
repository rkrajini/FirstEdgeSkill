📲 How to Add this Skill to Google AI Edge Gallery

Prerequisites: Google AI Edge Gallery installed on your phone/device with your downloaded Gemma model.

Method A: Direct Import via Local Storage / ADB

  1. Run the automated packager script in this folder: python package_skill.py (Generates bilingual-photo-poet-skill.zip and an unzipped folder).
  2. Push the skill folder to your Android device's Download directory via ADB or USB: 
    adb push bilingual-photo-poet /sdcard/Download/
  3. Open Google AI Edge Gallery, go to Agent Skills with your downloaded Gemma model.
  4. Tap the Skills chip → Tap (+) → Select Import local skill.
  5. Pick the folder containing SKILL.md. The skill is now active offline!

Method B: Load via URL / GitHub Pages

Push this folder to a GitHub repository, enable GitHub Pages (with a .nojekyll file), and tap Import via URL inside the Edge Gallery app.
